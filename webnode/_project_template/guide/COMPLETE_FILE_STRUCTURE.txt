================================================================================
EXECUTION FLOW SUMMARY
================================================================================

1. Browser Request → ServerNode (main.py)
   ↓
2. ServerNode → HTTPRequestsNode (parses request)
   ↓
3. HTTPRequestsNode → Middleware Chain:
   - ActionLoggerNode (logs request)
   - RateLimitNode (rate limiting)
   - AntiBotNode (blocks scrapers)
   - CSRFNode (token validation)
   ↓
4. Security → RouterNode (finds matching route)
   ↓
5. RouterNode → URLNode (path matching, extracts params)
   ↓
6. URLNode → LogicNode (executes business logic from static/)
   ↓
7. LogicNode → RenderNode (renders template with context)
   ↓
8. RenderNode → ServerNode (sends response to browser)
