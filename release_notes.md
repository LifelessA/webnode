# WebNode v1.3.0 🚀 The AI & Visual Development Update

This release brings revolutionary updates to the WebNode framework, introducing powerful new tools to build web applications visually and programmatically!

### 🔥 Major Features
* **AI Editor Integrated**: A next-generation AI backend that can generate nodes, HTML, CSS, and Python logic through natural language. (`ai_editor/`)
* **Thread-safe SQLite Database**: Core database module (`core.db`) upgraded with thread isolation, WAL mode, and query retry mechanics.
* **Full File Structure Scaffolding**: `node-web startproject` now copies the entire framework toolkit including plugins, logs, and security features.
* **Plugin Architecture**: Added middleware support with standard plugins (`RateLimitNode`, `CSRFNode`, `AntiBotNode`, and `ActionLoggerNode`).
* **Dynamic Package Discovery**: Assets are correctly bundled automatically for PyPI distribution.

Enjoy building your graph of nodes!
